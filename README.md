# Whiskers at home 🐱

A live dashboard for tracking neighbour cats — built with React, Vite, and Firebase.

## Features
- 6 cats with check-in/out (photo upload OR manual)
- Live "on air" green pulse + auto-checkout after 3 hr
- Shared real-time data via Firebase across all devices
- Photo blog per cat
- Cute illustrated floor plan with corridor + balcony
- 4 YouTube playlists (Chill & Fun · Lofi · Nature · Cat Purrs)
- Editable cat profile photos
